# Conversores em Python

Programas de conversão de tempo, distância em temperatura construídos em Python. 

## O que tem aqui

- **Conversor de tempo** — converte minutos e horas de forma separada
- **Conversor de distância** — converte entre unidades de distância (milhas, km e metros)
- **Conversor de temperatura** — converte entre Fahrenheit e Celsius

## Como usar

Dentro de cada arquivo, comentários explicam o código e dão instruções. Cada arquivo pode ser rodado direto pelo terminal.
